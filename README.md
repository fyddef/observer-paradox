# 👁️ Парадокс Наблюдателя (Observer's Paradox)

> *История — это не прошлое. Это симуляция, которая обновляется в реальном времени.*

**Парадокс Наблюдателя** — это нарративная браузерная игра-головоломка, которая ломает четвертую стену. Вы выступаете в роли Хранителя хронологии, чья задача — находить и устранять темпоральные аномалии. Но будьте осторожны: иногда аномалия — это вы сами.

🔗 **[Играть прямо сейчас (GitHub Pages)](https://твой-ник.github.io/имя-репозитория/)** *(замени ссылку на свою)*

## 🎮 Особенности игры
- **Сюжетный твист**: Игра начинается как классический исторический квест, но в финале использует реальную дату и время пользователя, чтобы создать эффект погружения и сломать четвертую стену.
- **Процедурный звук (Web Audio API)**: Никаких внешних аудиофайлов! Все звуковые эффекты (гул сканера, печатная машинка, глитчи) генерируются математически прямо в браузере.
- **Адаптивный кибер-дизайн**: Сочетание эстетики "цифрового архива" и CRT-мониторов (сканлайны, анимации дрожания, глитч-эффекты при смене фаз игры).
- **Нулевые зависимости**: Чистый HTML, CSS и Vanilla JavaScript. Работает молниеносно на любом устройстве.

## 🛠️ Технологии
- `HTML5` (Семантическая разметка)
- `CSS3` (CSS-переменные, анимации, Grid, Flexbox, Glassmorphism)
- `JavaScript (ES6+)` (Асинхронность, Web Audio API, манипуляции с DOM)
